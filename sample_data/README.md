# Sample data

`sample_5_marla_package.pdf` is a synthetic, CAD-style drawing set for a
5 marla (25'x45') G+1 house drawn at 1/8"=1'-0": ground and first floor
plans (double-line walls, door swings, room labels with sizes, plot and
covered-area notes), Section A-A with level marks, a front elevation, and a
foundation plan with footing/column schedules. It is generated by
`make_sample_package.py` (no real architect's drawing is bundled) and its
exact dimensions are the ground truth for `tests/test_package_analysis.py`.

Upload it in Step 1 (choose "5 marla") and use "Continue without AI" in
Step 2 to see what the app reads from a CAD drawing set without any AI call.
You can also drop your own drawings (PDF/PNG/JPG) here for local testing.
